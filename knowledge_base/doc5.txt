Weaviate - это векторная база данных с открытым исходным кодом, разработанная для хранения и поиска объектов на основе их векторных представлений.

Векторные базы данных отличаются от традиционных реляционных баз тем, что они оптимизированы для семантического поиска. Вместо точного совпадения значений они находят объекты с похожими векторными представлениями.

Основные возможности Weaviate:
- Хранение векторов и метаданных
- Семантический поиск по близости векторов
- Гибридный поиск (векторный + ключевые слова)
- Модули для автоматического векторизации текста и изображений
- GraphQL API для запросов

Weaviate широко используется в приложениях RAG, поисковых системах и рекомендательных системах.

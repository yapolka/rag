RAG (Retrieval-Augmented Generation) - это архитектура для языковых моделей, которая сочетает извлечение информации из внешних источников с генерацией текста.

Традиционные языковые модели ограничены знаниями, на которых они были обучены. RAG решает эту проблему, позволяя модели обращаться к актуальной информации из внешних баз знаний.

Процесс работы RAG:
1. Пользователь задает вопрос
2. Система ищет релевантные фрагменты в базе знаний
3. Найденные фрагменты передаются в языковую модель как контекст
4. Модель генерирует ответ, опираясь на предоставленный контекст

Преимущества RAG:
- Снижение галлюцинаций модели
- Возможность работы с актуальной информацией
- Прозрачность - можно отследить источники ответа
- Не требует переобучения модели при обновлении знаний
